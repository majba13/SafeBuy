# SafeBuy Backend (NestJS)

## Setup

1. Install dependencies:
   ```bash
   npm install -g @nestjs/cli
   npm install
   ```
2. Create a `.env` file with your MongoDB, Cloudinary, Firebase, and JWT secrets.
3. Run in development:
   ```bash
   npm run start:dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```

## Deployment
- Deploy to Railway or Render (Node.js service)
- Set environment variables in the deployment dashboard
