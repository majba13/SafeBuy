# SafeBuy Frontend (Next.js)

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Create a `.env.local` file with your API base URL, Cloudinary, and Firebase keys.
3. Run in development:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   npm start
   ```

## Deployment
- Deploy to Vercel (recommended)
- Set environment variables in the Vercel dashboard
