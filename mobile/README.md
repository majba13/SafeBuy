# SafeBuy Mobile App (Expo)

## Setup

1. Install dependencies:
   ```bash
   npm install -g expo-cli
   npm install
   ```
2. Start the app:
   ```bash
   npm start
   ```
3. Run on Android/iOS/Web:
   ```bash
   npm run android
   npm run ios
   npm run web
   ```

## Deployment
- Use Expo Go for development
- Build APK/IPA for app stores using Expo Application Services
